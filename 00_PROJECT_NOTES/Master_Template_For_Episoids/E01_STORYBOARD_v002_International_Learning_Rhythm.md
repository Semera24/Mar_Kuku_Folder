# EPISODE_001 — Storyboard v002

## Mar's Big Counting Adventure — Learn Numbers 0 to 10

**Format:** 1920 × 1080, 30 fps, horizontal YouTube episode  
**Target duration:** approximately 10 minutes 30 seconds  
**Audience:** preschool children, primarily ages 2–5  
**Primary language:** English  
**Future versions:** Amharic and other language dubs using the same visuals  
**Main character:** Mar  

## International Preschool Design Rules

1. **Visual first:** a child should understand the action even with sound off. Use numbers, objects appearing, Mar pointing, clapping, and clear facial reactions.
2. **One repeatable learning routine:** *Mar asks → one object appears → the number is said/sung → quiet repeat gap → Mar celebrates.* Use the same rhythm in every object chapter.
3. **Attention beats, not frantic cutting:** change something meaningful every 3–5 seconds in the hook and every 4–7 seconds afterward: object arrival, number pop, Mar action, small camera push, or scene change. Do not cut randomly every two seconds.
4. **Clear sound:** one friendly childlike female voice/singer; slow pronunciation; no dense dialogue; 2–3 second repeat gaps after every number.
5. **Original identity:** warm Ethiopian village world, Mar, DoroNesh colours, original melodies and scripts. Never copy another channel's characters, songs, branding, shot sequence, or lyrics.
6. **Localization-ready:** do not bake English words into visual art. Keep spoken/sung audio on separate tracks. Numbers remain visual and universal.
7. **Calm, parent-safe pacing:** no flashing, loud surprises, aggressive sound effects, or constant movement. Rewatchability comes from predictable routines, not overstimulation.

## Visual Rules

- Primary setting: `BG_Village_Open_Yard_v002.png`.
- Mar begins already in the village; no walking entrance.
- Keep Mar in the left or centre-left area when a large counting object is on the right.
- Use hard cuts between different Mar PNG poses. Inside a pose, use only gentle purposeful keyframes: breathing sway, small nod, one step, point, clap, or controlled bounce.
- Use the full Number 0–10 character set in the main counting chapter.
- Background sheep remain small and quiet. Use Grazing normally; switch briefly to Head Up for Number 10.
- Each object chapter uses duplicates of one clean PNG prop. Objects appear one at a time, then remain visible for the final count.
- The final celebration overlay stays light and must not hide Mar, Number 10, or the chicks.

## Reusable Object Chapter Pattern

| Beat | Typical Duration | Visual / Audio Action |
|---|---:|---|
| Invite | 4–6 sec | Mar points and asks: “Can you count the eggs with me?” |
| Reveal | 4–5 sec each | One new object arrives; Mar reacts; voice sings/says the object number. |
| Repeat gap | 2–3 sec each | Object remains still and music softens so the child can repeat. |
| Review | 7–10 sec | All objects remain visible; count together once more. |
| Reward | 4–6 sec | Mar claps, waves, or celebrates with one gentle sound accent. |
